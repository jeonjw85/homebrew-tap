# jeonjw85/homebrew-tap

[profNote](https://github.com/jeonjw85/profNote) Homebrew cask.

```bash
brew install --cask jeonjw85/tap/profnote
brew upgrade --cask profnote
```

Cask version follows published profNote GitHub Releases. The bump workflow runs hourly and can be started by hand from the Actions tab.
