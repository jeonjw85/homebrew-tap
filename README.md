# jeonjw85/homebrew-tap

Homebrew casks for [profNote](https://github.com/jeonjw85/profNote) and [Graft](https://github.com/jeonjw85/Graft).

## Graft

```bash
brew install --cask jeonjw85/tap/graft
brew upgrade --cask graft
```

## profNote

```bash
brew install --cask jeonjw85/tap/profnote
brew upgrade --cask profnote
```

Cask versions follow published GitHub Releases. The bump workflows run hourly and can also be started by hand from the Actions tab.
